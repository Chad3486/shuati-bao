# 刷题宝 📱

纯本地刷题 App：把 Word 题库或范式文本导入手机，自动解析成结构化题目，随时随地刷题。无服务器、无注册，数据只存在本机（IndexedDB）。

## 下载安装

- **APK（推荐）**：到 [Releases](../../releases) 下载最新 `shuati-bao-v<版本号>.apk`（v1.8.17 起附件名带版本号，更早版本叫 `default.apk`），传到手机安装（需允许未知来源），要求 Android 5.0+。
- **网页版**：本地跑 `node build-single.mjs` 生成 `dist/刷题宝-单文件版.html`，用浏览器打开即可，与 APK 同一份代码，数据同样存本地（产物不进仓库，避免同一份文件存两遍）。
- **自己构建**：见下方「从源码构建」。

## 导入题库

推荐「**范式导入**」：答案直接写在题目里，导入时不需要任何答案对齐、零 API 调用、秒级完成。

```
# 第1章 电力电子器件
## 1.1 电力二极管

【单选】1. 电力二极管属于（ ）器件。
A. 不可控器件
B. 半控器件
C. 全控器件
答案：B
解析：只有通、断两种状态，属不可控器件。
```

- 题号行可省略（自动编号）；判断题答案写 `对/错`，多选写 `ABD`，多空填空用 `|||` 分隔；答案留空即「缺答案」，题目照常入库。
- 「**Word 转换器**」可把老格式文档（题目 + 文末答案表）本地转为范式文本，无 AI。
- 「**导入文件（Word）**」支持 DOCX 纯本地解析，可题目文件与答案文件一起选，按 章/节/题号 匹配答案与解析。
- 试卷照片 / 截图 / 整页题图的 Word 走 **AI 视觉识别**转写（需在设置里配一个支持图片的模型）。
- 导入前有解析预览：题目数 / 有答案 / 缺答案 / 格式错误，错误带行号，不会静默丢题。

## 主要功能

单选 / 多选 / 判断 / 填空；按章节练习；模拟考试（限时、交卷后逐题解析、一键重做错题）；背题模式；答题卡；全局搜题；练习记录；错题本与收藏夹；统计（章节正确率、日答题量）；日间 / 夜间主题；题库 JSON 备份与范式导出。

## 三个「体检类」功能（v1.8.20）

这三件事的共同点是：只靠本地数据算，不需要 AI、不需要服务器、断网可用。

- **题库体检**：导入后点「🩺 体检」，自动查 9 类机器能确定的问题——答案不在选项里、选项文本重复、选项字母跳号、题型与答案数量不符、解析与答案矛盾、判断题格式异常、题干疑似截断、缺解析、疑似重复题。点任意一条直达该题的修改面板；可导出 Markdown 报告。**只判断可以确定的问题**，解析写得对不对这类语义问题不判。
- **能力估分**：按你做过的题和题目难度（本地 Elo / 1PL）推算这套题库的卷面分，给预计区间、及格概率和最该补的章节。数据不足 30 题时会提示再练多少题。
- **每日一练**：首页一键，每天一组 8 题（错题 3 + 新题 4 + 复习 1，某类不够自动回填）。**同一天的题集固定**（做一半退出再进还是同一组），连续天数从练习记录推导，跨天自动结算。

AI 功能均为可选（配 Key 才用）：缺答案的题让 AI 解、答案文件智能对位、乱排版文档转范式。不配 Key 时完全本地、零调用、断网可用。

## 从源码构建 APK

仓库已配好 GitHub Actions，无需本地环境：Actions → **Build ShuatiBao APK** → Run workflow → 等 3~5 分钟后从 Artifacts 下载。

本地构建（需 JDK 17 + Android SDK + Gradle 8.4+、Node 18+）：

```bash
node build-single.mjs                 # 重建单文件版，并把产物拷进 apk-src（脚本自己拷，无需手 cp）
gradle -p apk-src :app:assembleRelease
# 产物：apk-src/app/build/outputs/apk/release/app-release.apk
```

打包用 release 变体，但签名沿用仓库里固定的 `apk-src/app/debug.keystore`——这样做只是为了老用户
能直接覆盖升级（换 keystore 会签名冲突，必须卸载重装）；`debuggable` 已显式关掉，不会发可调试包。

改完 `js/`/`css/` 记得重跑 `node build-single.mjs` 并提交 `apk-src/app/src/main/assets/app.html`，
否则 CI 的 `Check committed bundle is up to date` 会拦下来（历史上就是这份产物落后一个版本）。

测试（零依赖，Node 18+ 直接跑）：

```bash
node --test scripts/parse-regression.test.js   # 解析器回归：答案污染 / 卷末答案表 / 判断题等
node scripts/smoke-lite.test.js                # 冒烟：AI 标注装配链路
```

发版只靠 tag，不用手改 versionCode：

```bash
git tag v1.8.18 && git push origin v1.8.18
gradle 的 versionName / versionCode 由 CI 按 tag 注入（1.8.18 → versionCode 10818），
build-single.mjs 会把同一个版本号写进 App 内显示的 VERSION。
```

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | 原生 JS（无框架），单文件打包，离线可用 |
| 存储 | IndexedDB |
| Word | mammoth.js |
| AI（可选） | OpenAI 兼容接口 |
| APK 壳 | Android WebView（minSdk 21），见 [apk-src/](apk-src/) |

```
├── index.html / css / js   # 网页版源码
├── dist/                   # 单文件打包产物（build-single.mjs 生成，不入库）
├── apk-src/                # Android WebView 壳工程
├── build-single.mjs        # 单文件打包脚本
└── .github/workflows/      # CI 构建 APK
```
