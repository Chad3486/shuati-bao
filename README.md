# 刷题宝 📱

纯本地刷题 App：把 Word 题库或范式文本导入手机，自动解析成结构化题目，随时随地刷题。无服务器、无注册，数据只存在本机（IndexedDB）。

## 下载安装

- **APK（推荐）**：到 [Releases](../../releases) 下载最新 `shuati-bao-v*.apk`，传到手机安装（需允许未知来源），要求 Android 5.0+。
- **网页版**：直接用浏览器打开仓库里的 `dist/刷题宝-单文件版.html`，功能一致，数据同样存本地。
- **自己构建**：见下方「从源码构建」。

## 导入题库

推荐「**范式导入**」：答案直接写在题目里，导入时不需要任何答案对齐、零 API 调用、秒级完成。

```
# 第1章 电力电子器件
## 1.1 电力二极管

【单选】1. 电力二极管属于（ ）器件。
A. 不可控器件
B. 半控器件
C. 全控器件
答案：B
解析：只有通、断两种状态，属不可控器件。
```

- 题号行可省略（自动编号）；判断题答案写 `对/错`，多选写 `ABD`，多空填空用 `|||` 分隔；答案留空即「缺答案」，题目照常入库。
- 「**Word 转换器**」可把老格式文档（题目 + 文末答案表）本地转为范式文本，无 AI。
- 「**导入文件（Word）**」支持 DOCX 纯本地解析，可题目文件与答案文件一起选，按 章/节/题号 匹配答案与解析。
- 试卷照片 / 截图 / 整页题图的 Word 走 **AI 视觉识别**转写（需在设置里配一个支持图片的模型）。
- 导入前有解析预览：题目数 / 有答案 / 缺答案 / 格式错误，错误带行号，不会静默丢题。

## 主要功能

单选 / 多选 / 判断 / 填空；按章节练习；模拟考试（限时、交卷后逐题解析、一键重做错题）；背题模式；答题卡；全局搜题；练习记录；错题本与收藏夹；统计（章节正确率、日答题量）；日间 / 夜间主题；题库 JSON 备份与范式导出。

AI 功能均为可选（配 Key 才用）：缺答案的题让 AI 解、答案文件智能对位、乱排版文档转范式。不配 Key 时完全本地、零调用、断网可用。

## 从源码构建 APK

仓库已配好 GitHub Actions，无需本地环境：Actions → **Build ShuatiBao APK** → Run workflow → 等 3~5 分钟后从 Artifacts 下载。

本地构建（需 JDK 17 + Android SDK + Gradle 8.4+）：

```bash
gradle -p apk-src :app:assembleDebug
```

改了网页代码后先重建单文件再构建：

```bash
node build-single.mjs
cp "dist/刷题宝-单文件版.html" apk-src/app/src/main/assets/app.html
```

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | 原生 JS（无框架），单文件打包，离线可用 |
| 存储 | IndexedDB |
| Word | mammoth.js |
| AI（可选） | OpenAI 兼容接口 |
| APK 壳 | Android WebView（minSdk 21），见 [apk-src/](apk-src/) |

```
├── index.html / css / js   # 网页版源码
├── dist/                   # 单文件打包产物
├── apk-src/                # Android WebView 壳工程
├── build-single.mjs        # 单文件打包脚本
└── .github/workflows/      # CI 构建 APK
```
