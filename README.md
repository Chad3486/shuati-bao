# 刷题宝 📱

一个纯本地的移动端刷题应用——把 Word 题库文件（或直接粘贴范式文本）导入手机，自动解析成结构化题目，随时随地刷题。

无需服务器、无需注册，所有数据存在手机本地（IndexedDB）。

## 功能

### 🧩 范式导入（推荐 · 答案零对齐）
答案直接写在题目里，导入时**不需要任何「答案对齐」**——不再有扫不上的题，1000 题也是一次线性扫描、零 API 调用、秒级完成。

```
# 第1章 电力电子器件
## 1.1 电力二极管

【单选】1. 电力二极管属于（ ）器件。
A. 不可控器件
B. 半控器件
C. 全控器件
答案：B
解析：只有通、断两种状态，属不可控器件。
```

- **一题三要素**：题号行（可省略，自动顺序编号）、选项行（选择题才要，每行一个）、**答案行**（有这行就不用对齐）
- 题型标记 `【单选】/【多选】/【判断】/【填空】` 可省略，会按选项与答案自动推断；`## 判断题` 这类小节标题也能定题型
- 判断题答案写 `对/错`，多选写 `ABD`，多空填空用 `|||` 分隔；**答案留空 = 缺答案**，题目照常入库，之后自己填或让 AI 解
- 兼容简答/名词解释/计算/论述等题型（按填空处理，答案自己写）
- **Word 转换器**：把老格式文档（题目 + 文末答案表 / 题干内嵌「（答案：B）」）一键转成范式文本，本地按 章/节/题号 匹配答案，无 AI、无对齐
- **解析预览**：导入前先给出「题目数 / 有答案 / 缺答案 / 格式错误」，错误带行号逐条列出，**有问题的题不会静默丢失**
- **AI 解题（可选）**：一键让 AI 把缺答案的题做出来写回文本框，人工核对后再导入
- **题库可导出范式**：导出的文本在 Word 里补答案 / 改题干 / 加题后，再回「范式导入」贴回来覆盖建库

### 📥 智能导入（DOCX 自动解析）
- 支持 **DOCX（Word）**，可多文件批量导入
- **图片导入（AI 视觉识别）**：直接把试卷照片/截图（JPG/PNG）扔进导入页，由视觉模型转写为范式文本后解析入库；图片型 Word（整页都是题图）在本地认不出时也会自动走视觉识别兜底。需在「设置」单独配置支持图片的视觉模型；图片自动压缩到长边 1600px 再上传
- **题目文件 + 配套答案文件一起选**：自动识别答案文件（文件名含「答案」或内容为答案格式），按 **章 / 节 / 题号** 精确匹配，答案与**解析**一并入库
- **AI 辅助录入（可选开关）**：本地规则匹配不到的题，由 AI 直接**从答案文件原文智能对位**填入——答案照抄原文而非 AI 做题，正确率高；回填前过同一套题型校验（单选/判断必须单字母且在选项内），过不了校验的宁缺毋错。需在「设置」配置 API Key；关闭或无 Key 时纯本地零调用
- **纯本地正则解析**：不调用 AI、无需 API Key、零费用，秒级完成
- 答案格式全支持："2、答案：A（解析：…）" / "1.C 2.A 3.B" / "1.ABD 2.BC"（多选） / "题号：1 答案：C" / "1、对 2、错"（判断） / 纯序列 "A B C D"；答案标注「（存疑）」会保留提示
- **「答案解析版」内嵌格式**：答案与解析直接写在题目下方（"答案：D    解析：…"），无需单独答案文件，答案与解析一并入库
- **题型标题行免序号**：无论"一、单选题"还是单独成行的"单选题 / 多选题 / 判断题"，都能正确识别并区分题型
- **多选答案兼容顿号/逗号**："答案：A、B、C、D" / "A,B" / "ABCD" 均可；带分组的复合答案（如"单端：A、C；双端：B、D、E"）也能识别（严格形状校验，宁缺毋错）
- 自动清除页眉页脚噪声（"统一服务热线"等）、跨页断行自动拼接
- **题型小节感知**：识别"一、单选题 / 二、多选题 / 三、判断题"结构，各节题号独立不互相覆盖
- 选项乱序（转制文档常见）自动重排，题干含"A、B、C三相"等字样不会误判为选项，残缺题自动跳过并报告

### ✏️ 题库管理
- **题干搜索 + 状态筛选**：题库多也不用一直往下翻——按题干 / 选项 / 答案实时搜索，按「错题 / 未答 / 答对 / 收藏 / 缺答案 / 有解析」筛选，章节一键折叠 / 展开
- 题库重命名、按小节分组选题练习；**缺答案的题也能勾选练习**，练习中点右上角 ✎ 自己填答案
- 删除题目进**回收站**（可恢复 / 彻底删除需二次确认）
- 补答案：上传答案文件本地匹配（免费，支持章/节/题号精确对位与解析入库），对不上的可一键「AI 智能对位」兜底 ｜ AI 解答（可选，需在设置里填 AI 接口）
- AI 校验答案并补解析（可选）

### 📝 刷题体验
- 单选 / 多选 / 判断 / 填空
- **按章节练习**：练习设置里勾选题库后还能再按章节勾选，只练想要的章节；首页题库多时支持搜索 / 排序 / 展开收起
- **模拟考试模式**：限时（按题量自动 / 自定义 / 不限时），作答时**不给对错**，可自由跳题改动；交卷（或时间到自动交卷）后统一判分，出成绩单 + **逐题解析**（按 全部/答错/未答/答对 筛选、上一题下一题翻阅、题号速览跳题），可一键重做错题
- **答题卡**：题号总览，答对 / 答错 / 未答 / 收藏一眼看清，点题号直接跳题
- **学习模式也有逐题解析**：刷完一轮后同样能逐题回看你的答案、正确答案与解析
- **背题模式**：答题页右上 📖 一键进入，直接亮出正确答案与解析、不用作答就能自由翻题，适合考前快速过题
- **全局搜题**：首页「🔍 搜题」跨全部题库搜题干 / 选项 / 答案，结果可直接收藏或一键开练
- **练习记录**：每轮练习 / 交卷后自动存一条记录，统计页「📋 练习记录」里可回看每一次的逐题解析
- **错题本 + 收藏夹**：底部「复习」页两个视图——错题自动聚合（含重做），★ 收藏夹跨题库集中管理收藏题、一键收藏练习
- 答题进度自动保存，中途退出可继续
- 日间 / 夜间主题（可跟随系统）
- 统计页：**章节正确率**（薄弱章节 <60% 置顶，点某一行直接开练该章）+ 日答题量柱状图（窄屏自适应，杜绝横向溢出）
- 题库导出 / 导入 JSON 备份

## 从源码构建 APK

本仓库已配好 GitHub Actions，无需本地环境：

1. Fork 或直接使用本仓库
2. Actions → **Build ShuatiBao APK** → Run workflow
3. 等约 3~5 分钟 → Artifacts 下载 APK

本地构建（需要 JDK 17 + Android SDK + Gradle 8.4+）：

```bash
gradle -p apk-src :app:assembleDebug
# 产物：apk-src/app/build/outputs/apk/debug/app-debug.apk
```

改了网页代码后先重建单文件再构建 APK：

```bash
node build-single.mjs
cp "dist/刷题宝-单文件版.html" apk-src/app/src/main/assets/app.html
```

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | 原生 JS（无框架），单文件打包（离线可用） |
| 存储 | IndexedDB（题库/答题记录/回收站） |
| Word | mammoth.js |
| AI（可选） | OpenAI 兼容接口（默认 DeepSeek），用于「文件 → AI 转范式」（只排版、答案照抄原卷）、「AI 补答案」（只解缺答案的题）与「AI 智能对位」（答案对齐） |
| APK 壳 | Android WebView（minSdk 21），[apk-src/](apk-src/) |

目录结构：

```
├── index.html / css / js   # 网页版源码（extract 解析 / canon 范式 / llm AI / db 存储 / app 页面 / quiz 会话）
├── dist/刷题宝-单文件版.html  # 单文件打包产物（手机浏览器直接可用）
├── apk-src/                 # Android WebView 壳工程
├── build-single.mjs         # 单文件打包脚本
└── .github/workflows/       # CI 构建 APK
```

## 使用建议

- 首次使用：首页「**范式导入**」→ 填入/粘贴范式文本（或把老文档丢进「Word 转换器」转一下）→ 解析预览确认 → 导入建库；这是**答案零对齐**的方式，最稳
- 已经有 Word 题库、不想手工整理：用「导入文件（Word）」纯本地解析建库
- 手上是排版很乱的 Word（多栏、答案表分散）：「范式导入」→ 点「**① 文件 → AI 转范式**」选原卷（题目与答案文件可一起选），AI **只做排版、答案照抄原卷、不做题**，转完自动填进文本框并出预览，核对后点「导入题库」（需先在「设置」里配 API Key）
- **图片型 / 扫描版文件（PDF 扫描件、整页截图的 Word）**：这类文件没有文字层，导入时会自动 OCR 识别（引擎与中文语言包已离线打包，首次识别需加载）；识别率取决于图片清晰度，导入后请抽查核对
- 原卷本身没答案：导入后在题库「**补答案**」页点「**方式二 · AI 解答剩余题目**」，AI 只解缺答案的题、**已有答案一律不动**，解出的标「AI 解答·需核对」（有费用预估确认，可随时暂停）；也可随时「**导出 Word（.docx）**」在 Word / WPS 里改完，回「范式导入」点「Word 转换器」选这份 .docx 一键导回
- 题库里的题也能整体导出成范式 Word：题库详情页「导出范式 Word」
- 答案总有个别扫不上：「AI 对答案」保留可用，但 1000 题逐题对位偏慢，建议先用上面的「文件 → AI 转范式」整份重排后再导入
- 题库重要的话记得定期「导出备份」JSON

- **模拟考试模式**：限时（按题量自动 1 分钟/题 / 自定义 / 不限时），作答时不给对错、可自由跳题改动，时间到自动交卷；交卷后统一判分出成绩单（得分 / 答对 / 答错 / 未答 / 用时）+ 错题解析速览，可一键重做错题
